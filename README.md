# Mecanum Car Simulator (C++)

## Project Overview

This repository contains a C++ academic project developed in 2025 to explore the software design of a four-wheel Mecanum car.

The project focuses on representing individual motors, implementing directional movement commands, and experimenting with a console-based vehicle visualization.

## Features

- Four-motor representation for a Mecanum-wheel vehicle
- Forward and backward movement commands
- Left and right turning commands
- Motor speed control logic
- Console-based user input
- ASCII-grid visualization concept

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Classes and methods
- Basic robotics and motor control concepts
- Console programming

## Project Files

| File | Purpose |
|---|---|
| `Car.cpp` | Vehicle behavior and motor control logic |
| `Motor.h` | Motor class definitions |
| `Simulator.cpp` | Console-based simulation and visualization logic |
| `main.cpp` | Main application entry point |

## Project Status

**Completed academic project — 2025.**

This repository preserves the original coursework implementation. It is no longer actively developed or maintained.

## Known Limitations

- The simulation and vehicle position updates are incomplete.
- Some declared functions and interfaces are not fully implemented.
- The original source files may require additional work before the program can compile and run successfully.

## Learning Outcomes

This project helped me practice object-oriented programming, C++ class design, organizing software into multiple source files, and modeling motor-driven vehicle behavior.

## Note

This is a software-oriented academic project and should not be interpreted as a fully functional physical Mecanum robot implementation.
